Problem

경로 생성 성공이 실제 주차 성공을 보장하지 않았습니다

주차 공간까지 연결되는 경로가 있어도 차량 자세, 후진 진입점, 제어기가 추종할 수 있는 곡률이 맞지 않으면 충돌하거나 목표에 도달하지 못했습니다.

Personal role

팀장과 주차 경로계획

통합 기준과 일정, 평가 결과를 관리했고 Hybrid A*, staging 전략, Reeds–Shepp 정밀 정렬을 구현했습니다.

Boundary

주차 작업은 페어 프로그래밍으로 수행

경로계획은 주차 제어 팀원과 페어 프로그래밍으로 개발했습니다. 최종 평가 수치는 개인 단독 결과가 아니라 6인 팀 결과입니다.

02 / ARCHITECTURE

Supervisor와 기능 모델 사이의 책임을 분리

미션 상태, 종·횡방향 제어, 주차 경로와 CarMaker 입출력의 경계를 먼저 고정해 각 담당자의 모델이 통합 시점에 같은 신호 계약을 사용하도록 맞췄습니다.

03 / DECISION

탐색·진입·정렬을 한 알고리즘에 몰아넣지 않았습니다

Hybrid A*로 장애물을 피해 주차 영역에 접근하고, staging point에서 자세를 안정화한 뒤 Reeds–Shepp 구간으로 최종 정렬하는 단계형 전략을 선택했습니다.

Decision 1

Hybrid A*로 차량 운동학을 반영

격자 최단경로만 사용하지 않고 조향·방향 상태를 포함해 실제 차량이 추종할 수 있는 후보 경로를 만들었습니다.

Decision 2

Staging으로 진입 상태를 표준화

바로 슬롯을 향하지 않고 후진이 가능한 위치·자세를 먼저 확보해 초기 조건 변화에 대한 실패를 줄였습니다.

Decision 3

Reeds–Shepp로 마지막 오차를 정렬

전·후진을 허용하는 정밀 구간으로 목표 자세와 위치 오차를 줄이고 제어기가 추종할 수 있게 경로를 연결했습니다.

04 / TEAM VALIDATION

실패가 컸던 케이스를 수치로 추적

Final set
